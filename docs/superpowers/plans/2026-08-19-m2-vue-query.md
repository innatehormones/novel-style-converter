## 任务分解

### Task 1：装依赖 + 注册 QueryClient

**步骤**：
1. `pnpm add @tanstack/vue-query` —— 装包
2. `src/main.ts` 加 `import { VueQueryPlugin, QueryClient } from '@tanstack/vue-query'`
3. `src/main.ts` 构造 `queryClient`：`retry: false`、`staleTime: 5000`、`refetchOnWindowFocus: false`
4. `app.use(VueQueryPlugin, { queryClient })`

**验证**：`pnpm dev` 启动，浏览器控制台无 vue-query 报错。

---

### Task 2：store.ts 缩成薄壳

**步骤**：
1. 删除 6 个 Map ref：`byTn / chaptersByBatch / sourcesByTn / resultsByTnChapter / promotedByBatch / previewsByBatchChapter`
2. 删除 6 个 `loadXxx` 函数
3. 删除 `promotedByBatch` + `loadPromotedByBatch` + `promote` 内的 `promotedByBatch.set`（死数据）
4. 删除 `refresh(batchId)` —— invalidate 替代
5. 删除 store 级 `loading / error` ref
6. store 引入 `useQueryClient()`
7. 重写每个 mutation 函数：调 IPC 后 `queryClient.invalidateQueries({ queryKey: [...] })`
   - `create` → invalidate `[''workflows'', tn_id]`
   - `stop` → invalidate `[''workflowChapters'', batchId]` + `[''workflows'']`（batchId 出现在多个 tn）
   - `retry` → invalidate `[''workflowChapters'', batchId]`
   - `deleteWorkflow` → invalidate `[''workflows'']`
   - `promote` → invalidate `[''workflows'']`（不影响 source DA）
   - `regeneratePreview` → invalidate `[''chapterPreviews'', batchId, chapterId]`
   - `commitPreview` → invalidate `[''chapterPreviews'', batchId, chapterId]` + `[''workflowChapters'', batch_id]` + `[''workflows'']`
   - `discardPreview` → invalidate `[''chapterPreviews'', batchId, chapterId]`
8. return 只保留 8 个 mutation 函数

**验证**：`vue-tsc --noEmit`，store.ts 无错。

---

### Task 3：TransformationNovelDetail.vue 读侧改 useQuery

**步骤**：
1. 加 `import { useQuery, useQueryClient } from '@tanstack/vue-query'`
2. 删 `useIntervalFn` import（轮询改 refetchInterval）
3. 替换 `sources = computed(() => store.sourcesByTn.get(tnId.value) ?? [])` 为：
   ```ts
   const sourcesQuery = useQuery({
     queryKey: [''transformationSourceChapters'', tnId],
     queryFn: () => listTransformationSourceChapters(tnId.value),
     refetchInterval: 5000,
   });
   const sources = computed<SourceChapterRow[]>(() => sourcesQuery.data.value ?? []);
   ```
4. 同理替换 `workflows` 读侧，refetchInterval 5000
5. 替换 `chaptersByBatch` 读侧为 useQuery，key `[''workflowChapters'', selectedWorkflowId]`，`enabled: computed(() => selectedWorkflowId.value !== null)`，refetchInterval 2000
6. 替换 `resultsByTnChapter` 读侧，复合 key `[''chapterWorkflowResults'', tnId, openSourceChapterId]`，`enabled` 控制
7. 删除 `workflowListPoll` / `chapterPoll` 两个 useIntervalFn 句柄
8. 删除 `loadAll()` 函数里对 `store.loadXxx` 的调用 —— 现在 useQuery 自动跑
9. 删除 store mutation 调用前的 `await store.loadXxx` 后续操作（mutation 自己 invalidate）
10. 模板里所有 `store.xxx.get(k) ?? []` 改成 `xxxQuery.data.value ?? []`

**验证**：
- `npm run tauri dev` 启动
- 进入转换工程详情
- 5s 轮询：工作流列表 + sources（含 `non_empty_result_count`）自动刷新
- 工作流详情弹窗：章节 2s 自动刷新
- 创建 / 停止 / 重试 / 删除工作流，操作后列表立即刷新
- 打开章节结果侧栏，列表正常显示
